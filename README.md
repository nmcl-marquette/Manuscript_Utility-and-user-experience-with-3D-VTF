# Subjective User Experience Analysis

This repository provides the code used to process and analyze the surveys and open-ended questionnaire reported in our 2026 manuscript.

 Mazorow RN, Rayes RK, Flores J, Guidarelli GH, Bassindale KD, Scheidt RA. Utility and User Experience with 3-Dimensional Vibrotactile Kinesthetic Feedback for Improving Reach-to-Grasp Accuracy and Efficiency After Stroke: A Case Series. Restorative Neurology and Neuroscience. 2026;0(0). doi:10.1177/09226028261429797
https://journals.sagepub.com/doi/full/10.1177/09226028261429797


## Surveys
After the last testing block of the last experimental session, participants were asked to complete a set of standard surveys quantifying subjective user experience in three domains (i.e., system usability, motivation, and user satisfaction), as well as to respond to a set of open-ended questions. 
- The System Usability Scale (SUS) served as the primary measure of system usability; the SUS assessed the usability of the vibrotactile feedback within the context of enhancing the accuracy and efficiency of goal-directed reaching movements. Participants responded to ten prompts using a 5-option Likert scale ranging from “Strongly Disagree” to “Strongly Agree”. Total SUS survey scores greater than or equal to 68 on a 100-point scale indicate passable usability. 
- The Intrinsic Motivation Inventory (IMI) assessed the extent to which participants perceived the supplemental vibrotactile feedback to be motivating via six dimensions of the original survey: interest/enjoyment, effort/importance, value/usefulness, perceived competence, perceived choice, and perceived pressure/tension. Participants responded to thirty-seven prompts using a 7-option Likert scale ranging from “Not-At-All True” to “Very True”. IMI scores greater than or equal to a value of 4 on the 7-point scale indicate favorable motivation to use the system; the only exception to this rule is the pressure/tension subsection, where lower scores are desired to indicate that the participant did not feel pressure or tense when using the system. Both the SUS and IMI use variations of the same questions (including reverse wording) to increase response reliability and to reduce response bias.
- The Quebec User Evaluation of Satisfaction with assistive Technology 2.0 (QUEST) assessed user satisfaction with six aspects of the supplemental vibrotactile feedback system: weight, safety, ease of use, comfort, effectiveness, and instructions for use. QUEST is comprised of two parts. For the first part, participants responded to six prompts using a 5-option Likert scale ranging from “Not-Satisfied-At-All” to “Very Satisfied”, addressing their satisfaction with the six items. Scores equal to or greater than a value of 3 on a 5-point scale indicated positive user satisfaction with the assistive device. The second part of QUEST asked participants to identify the three most important aspects (from the six listed above) contributing to their perceived satisfaction with the feedback system. 
- Participants were also provided with an opportunity to provide open-ended responses to a questionnaire.

## Documents provided
1. All Surveys_withScoring.docx - full surveys and questionnaire used and instructions for how to manually score each survey.
2. ResponseTemplate.xlsx - empty individual results template; each survey has its own sheet to transcribe individual responses to.
3. ID_001_Survey.xlsx and ID_002_Survey.xlsx - examples of completed individual survey response using ResponseTemplate.xlsx.
4. ConsolidateSurveys.m - MATLAB code that consolidates all individual .xlsx responses; generates .mat and .xlsx file with consolidation.

## How to use
1. Give your participants the surveys as provided. If you make changes to the question order or selection, this change will need to be carried throughout the MATLAB and R codes.
2. Create a copy of the "ResponseTemplate.xlsx", rename it "subID_Survey.xlsx", and input the participant's response to each question.
3. Edit line 10 in "ConsolidateSurveys.m" to include all participant IDs.
4. Run "ConsolidateSurveys.m".
5. Knit "SurveyAnalysis.Rmd".

## Personalizing the R output
By default, this generates figures with 95% confidence intervals as the error bars. This can be changed by searching and replacing '$ic' with another value (i.e., sd = standard deviation, se = standard error).
```r
avgSUS$ci_min <- avgSUS$mean - avgSUS$ic
avgSUS$ci_max <- avgSUS$mean + avgSUS$ic
```
Additionally, you can export all figures generated by commenting in lines 28-29 with an appropriate directory and file type.
